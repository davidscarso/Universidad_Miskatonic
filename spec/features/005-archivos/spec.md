# 005 · Archivos

**Estado:** implementado ✅

## Qué hace

Gestor de archivos estilo Google Drive para acceder a documentos, imágenes, videos y otros archivos ficticios de la universidad. Incluye panel de carpetas a la izquierda y contenido a la derecha con iconos representativos.

## Por qué

Permite a los usuarios acceder y explorar archivos de la universidad de forma visual e intuitiva, similar a servicios de almacenamiento en la nube como Google Drive.

## Criterios de aceptación

- [x] Página de archivos accesible desde navegación principal
- [x] Panel izquierdo con estructura de carpetas y subcarpetas
- [x] Panel derecho con iconos de archivos (texto, imágenes, videos)
- [x] Al hacer clic en un archivo, se abre modal con contenido
- [x] Modal redimensionable (ajustable en tamaño)
- [x] Iconos representativos según tipo de archivo
- [x] Header y footer consistentes
- [x] Tema oscuro aplicado
- [x] Responsive funciona correctamente

## Tipos de archivos soportados

- **Textos** — Documentos .txt, .md
- **Imágenes** — Archivos .jpg, .png
- **Videos** — Archivos .mp4
- **Otros** — PDF, presentaciones, etc.

## Fuera de alcance

- Subida real de archivos
- Edición de documentos
- Descarga de archivos
- Compartir archivos
- Búsqueda de archivos
