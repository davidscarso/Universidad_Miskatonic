# 003 · Página de Correo

**Estado:** implementado ✅

## Qué hace

Página de correo electrónico ficticio para el usuario logueado. Incluye sidebar con bandejas de entrada, salida, borradores y eliminados, botón de redactar, y lista de correos fake.

## Por qué

Es una de las funcionalidades principales del sitio universitario ficticio. Permite al usuario interactuar con un sistema de correo interno simulado.

## Criterios de aceptación

- [ ] Página de correo accesible solo para usuarios logueados
- [ ] Sidebar con 4 bandejas: Entrada, Salida, Borradores, Eliminados
- [ ] Botón "Redactar" visible
- [ ] Lista de correos fake en la bandeja de entrada
- [ ] Al menos 1 correo no leído destacado
- [ ] Header y footer consistentes con el resto del sitio
- [ ] Tema oscuro aplicado
- [ ] Responsive funciona correctamente

## Fuera de alcance

- Envío real de correos
- Adjuntar archivos
- Gestión de carpetas personalizadas
- Búsqueda de correos
