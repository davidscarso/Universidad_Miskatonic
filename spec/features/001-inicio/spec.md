# 001 · Inicio

**Estado:** implementado ✅

## Qué hace

Página principal que emula la portada de una univers ficticia del universo Lovecraft. Sirve como punto de entrada principal con navegación a las demás secciones del sitio (foro, email, escritorio remoto).

## Por qué

Es la primera impression que tienen los usuarios al acceder al sitio. Establece el tono Lovecraftiano y permite navegar al foro de investigación y otras secciones.

## Criterios de aceptación

- [ ] La página carga y muestra el nombre de la universidad
- [ ] El header contiene navegación principal (Inicio, Foro, Contacto)
- [ ] El botón de login es visible y funciona
- [ ] El tema oscuro estilo foros 2000s está aplicado
- [ ] Todo el contenido está en español
- [ ] El diseño es responsive (se adapta a diferentes pantallas)
- [ ] Hay elementos visuales temáticos Lovecraftianos
- [ ] El footer muestra información de copyright
- [ ] Los links de navegación funcionan correctamente
- [ ] La página es accesible (contraste de colores, estructura semántica)

- Foro de investigación (feature 003)
- Email (feature 004)
