# 001 · Inicio

**Estado:** implementado ✅

## Qué hace

Página principal que emula la portada de una univers ficticia del universo Lovecraft. Sirve como punto de entrada principal con navegación a las demás secciones del sitio (foro, email, escritorio remoto).

## Por qué

Es la primera impression que tienen los usuarios al acceder al sitio. Establece el tono Lovecraftiano y permite navegar al foro de investigación y otras secciones.

## Criterios de aceptación

- [x] La página carga y muestra el nombre de la universidad
- [x] El header contiene navegación principal (Inicio, Foro, Contacto)
- [x] El botón de login es visible y funciona
- [x] El tema oscuro estilo foros 2000s está aplicado
- [x] Todo el contenido está en español
- [x] El diseño es responsive (se adapta a diferentes pantallas)
- [x] Hay elementos visuales temáticos Lovecraftianos
- [x] El footer muestra información de copyright
